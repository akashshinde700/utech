# PWA Fix — 2026-10-28

**Complaint:** "PWA main proper nahi dikh raha mobile main."

**Root cause:** there was no PWA at all. The app had no web-app manifest, no
service worker, no PNG icons (only a blue SVG favicon), no `theme-color`, and
no Apple touch meta tags. On mobile it could only ever render as a plain
browser tab — never installable, never standalone.

## What was added

| Piece | File |
|---|---|
| Web app manifest (standalone, violet `theme_color #7c3aed`, any orientation) | `frontend/public/manifest.webmanifest` |
| Icons: 192, 512, maskable-512, apple-touch 180 — real PNGs generated in Chromium, violet gradient + white "U" | `frontend/public/icons/*.png` |
| Service worker: app-shell cache (network-first navigations, stale-while-revalidate assets); **`/api/` and `/uploads/` are never cached** so business data can't go stale offline | `frontend/public/sw.js` |
| Registration, production builds only (dev stays SW-free) | `frontend/src/main.jsx` |
| Manifest/theme/apple meta + `viewport-fit=cover` | `frontend/index.html` |
| Favicon recoloured blue → violet | `frontend/public/favicon.svg` |
| "Install app" button (appears only when `beforeinstallprompt` fires; iOS uses Share → Add to Home Screen) | `frontend/src/components/layout/InstallPrompt.jsx` |
| Notch/home-indicator safe areas on topbar + page bottom | `frontend/src/components/layout/AppLayout.jsx` |

## Verified (real Chromium, production `vite preview` build, 390×844)

- Manifest fetched 200, `display: standalone`, 512 icon present and loads.
- Service worker registers, activates and controls the page after reload.
- Offline reload still renders the app shell from cache (data calls fail
  honestly — they are never faked from cache).
- Mobile dashboard: no horizontal overflow (≤1px), drawer navigation works;
  screenshot in `audit/evidence-2026-10-28/mobile-dashboard.png`.
- Unit contract tests: `frontend/tests/unit/pwa.test.js` (5 tests — manifest
  fields, every declared icon exists at exactly its declared pixel size,
  HTML wiring, SW never caches `/api`, PROD-only registration).

Frontend suite: **181 tests pass** (was 176), lint clean, build passes and
emits `dist/manifest.webmanifest`, `dist/sw.js`, `dist/icons/*`.

**Not verified:** install prompt on a physical Android/iOS device (needs a
real device over HTTPS); iOS standalone behaviour is covered by meta tags
only. Deploy over HTTPS and test "Add to Home Screen" once on each platform.
